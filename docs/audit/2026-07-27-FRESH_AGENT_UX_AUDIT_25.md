## Agent Pain Points (UX Issues Encountered)

### CRITICAL — Blocked the agent

| # | Issue | Impact | Root Cause |
|---|-------|--------|------------|
| **P1** | `transcribe` tool returns JSON but the MCP client couldn't parse the response correctly | Agent had to write custom Python parser to extract transcript | Response format not documented; stdout buffering issue |
| **P2** | `srt.to_timeline` creates timeline with empty `source` field | Timeline.render fails validation | `srt.to_timeline` should accept `source_video` param or set it from context |
| **P3** | `music.search` uses `query` param but tool definition says `concept` | Agent tried `concept` first (failed), then `query` (also failed) | Inconsistent param naming; tool definition doesn't match implementation |
| **P4** | `music.search` returns no results for valid queries | Agent couldn't get any music track | Music index may not be built; no fallback behavior |
| **P5** | `music.assign` requires `path` (file path) but agent only has track metadata | Agent found tracks via `library.search` but couldn't extract the file path | Response schema inconsistency between `music.search` and `library.search` |

### HIGH — Degraded experience

| # | Issue | Impact |
|---|-------|--------|
| **P6** | No tool to list available music tracks | Agent must guess search queries |
| **P7** | `sfx.assign` not attempted (agent ran out of patience) | No SFX in final video |
| **P8** | No tool to add stickers/GIFs to timeline | No stickers in final video |
| **P9** | `voiceover.generate` not attempted | No voiceover (the original audio is the voiceover, but verifier doesn't detect it) |

### MEDIUM — Confusion

| # | Issue | Impact |
|---|-------|--------|
| **P10** | Multiple SRT files generated by `transcribe` (`.srt`, `.phrase.srt`, `.word.srt`, `.grouped.srt`) | Agent doesn't know which one to use |
| **P11** | `segment.analyze` and `srt.to_timeline` produce different segment counts (12 vs 45) | Agent uncertainty about which segmentation to use for b-roll |
| **P12** | Tool error messages are sometimes raw Rust errors, not agent-friendly | Agent can't diagnose issues easily |

## Recommended Fixes (Priority Order)

### Sprint 1 — Fix Agent-Facing API Issues (1-2 days)

1. **`srt.to_timeline` should accept `source_video` param** — Set `timeline.source` automatically
2. **`music.search` should work with simple queries** — Fix the index or add fallback behavior
3. **`music.search` response should include `path` field** — So `music.assign` can use it directly
4. **Add `help.tool` response for "how to add music"** — Guide the agent to the right tool chain

### Sprint 2 — Fill Pipeline Gaps (2-3 days)

5. **Audio clipping fix** — Set loudnorm default to -16 LUFS in timeline.render
6. **SFX at transitions** — Auto-add SFX on segment boundaries (or provide `sfx.auto_assign` tool)
7. **Sticker/GIF auto-placement** — Use `sticker.render` with speaker detection
8. **Section map generation** — `segment.analyze` should output section_map for composition scoring

### Sprint 3 — Production Quality (3-5 days)

9. **Voiceover detection** — `verify.production` should detect original audio as voiceover
10. **Duration optimization** — Agent should be able to set target duration
11. **video_keywords in timeline** — Pass agent-generated keywords to verify for context scoring
12. **Platform presets** — Auto-set aspect ratio, duration, fps based on target platform
